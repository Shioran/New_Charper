# New_Charper
New Charper es una aplicación web desarrollada con Spring Boot y React bajo el patrón MVC, que ofrece al usuario un espacio personal, seguro y motivador para:
-Registrar sus adicciones activas y la fecha de inicio de su proceso de recuperación.
-Visualizar en tiempo real cuántos días lleva sin recaer por cada adicción.
-Registrar recaídas con fecha, hora y motivo, para identificar patrones.
-Consultar un dashboard con estadísticas clave: días actuales, récord histórico y gráficas de progreso.
